# HCI_WE_173
#uu

Home-cooked meal delivery mobile app connecting local cooks, customers, and delivery riders.

## Repository Layout

```text
HCI_WE_173/
├── frontend/   # Expo React Native mobile app
├── backend/    # Backend notes / future API location
└── docs/       # Project planning, schema, UX, and team docs
```

## Run Frontend

```powershell
cd frontend
npm install
npx expo start -c
```

The MVP currently uses Expo SQLite inside the mobile app, so there is no separate backend server to run yet.
